21.11.2026. Вносим **одно** обновление действующего Apps Script бота. Ни школьный журнал, ни `Code.gs`, ни файлы «Текстории» не изменяем.

## Готово в GitHub

- ЕГЭ №9 — конкретные правила только по проверенной вставке букв **в разборе ошибочных рядов**. Ошибки выбора ряда не считаются доказательством ошибки в каждом слове.
- ЕГЭ №10 — проверенные буквы и ошибки по конкретным правилам приставок во всех пяти номерах. Сохраняем экзаменационный балл 0–5.
- ЕГЭ №11 — предыдущая доработка отправляет 23 категории суффиксов, старый балл 0–5 не меняется.
- Паронимоскоп — результаты по группам паронимов после 10 проверенных предложений.
- ЕГЭ №26 — отдельные средства связи и **комбинации** средств как единый тип задания; комбинированные ошибки не размазываются на все правила.
- Словарный штурм — до 20 конкретных слов, где были ошибки в подходе. Это *слова*, а не грамматические правила. При большем числе ошибок сообщается, сколько слов не вошло в компактный отчёт.
- ЛЕГОПУНКТ №16–20 — количество неудачных проверок по реально пройденным этапам разметки и пунктуации. Одна завершённая конструкция по-прежнему = одно предложение; эти данные *не равны* ошибке в правиле.
- ЕГЭ №8 (обе части), «Чумная больница» №14, три тренажёра №21 и «Нарешка» №22 уже отправляли категории; общий обработчик умеет преобразовывать их **без изменения самих игр**.
- Орфопонг остаётся без статистики по прежней договорённости.

## Где проверять

Наша таблица Telegram: https://docs.google.com/spreadsheets/d/13kcudUD6g9zHFIigT5NllxxeUUPZuDDZwFBXfGzOLoU/edit#gid=1457372779

Вкладка **«Тренажёры — навыки»**:

A — дата; B — ученик; C — Telegram ID; D — ID тренажёра; E — название;
F — ID попытки; G — ID навыка; H — правило или навык; I — проверок;
J — ошибок; K — верно; L — успешность; M — **тип диагностики**.

Число проверок в I **не обязательно равно** полю `total` в общем результате: это могут быть слова, примеры, дополнительные проверки после ошибки или попытки на этапе.

### Короткая проверка после развёртывания

1. Выполни в Telegram через кнопку бота один пятёрочный раунд в **«ПриставьГраде»** с хотя бы одной ошибкой.
2. В **«Тренажёры — результаты»** должна появиться одна запись: **из 5** (как раньше).
3. В **«Тренажёры — навыки»** должны появиться несколько строк по конкретным правилам приставок с общим одинаковым `ID попытки`.
4. Выполни один раунд в «Нарешке базы» №22, где саму игру менять не пришлось. Убедись, что появились строки по средствам выразительности.
5. Для «ЛЕГОПУНКТА» проверь отдельно: старый счётчик разобранных предложений увеличивается на 1, новые строки — по этапам.

Если общая строка есть, но подробных нет, открой **Apps Script → Выполнения** и проверь ошибки с префиксом `RULE_DIAGNOSTICS`. Нельзя автоматически восстанавливать детальные данные прошлых попыток из общего балла.

## Как интерпретировать статистику

- «Буква в слове · точная ошибка» — непосредственная проверка орфограммы.
- «Исправление букв после ошибки №9» — проверка **после** неверного выбора ряда, не в исходном ответе.
- «Тема комплексного задания» — тема вопроса, а не доказательство незнания каждого перечисленного средства связи.
- «Попытки на этапе разбора» — количество неверных попыток на этапе в ЛЕГОПУНКТЕ, а не количество ошибок в пунктограммах.
- «Конкретное словарное слово» — словарная единица, не правило.
- «Пунктограмма · ведущая категория задания» у №21 — предварительная классификация, не окончательный диагноз: в задании может быть несколько пунктограмм.

Пока это **сбор доказательств**. Объединять разные типы по одному «проценту освоения» нельзя. Следующая задача — аккуратно группировать сходные затруднения перед уроком с учётом типа и давности проверки.
