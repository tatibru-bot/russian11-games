# «Целую, милая» — подключение учебной диагностики в Telegram

### Что изменяется
- В игре появился отдельный **тип отчёта `skill_result`** для всех завершённых тематических тренировок, обучающих алгоритмов, двойников и повторения ошибок. Он содержит счётчики по правилам, неверным шагам, запросам подсказок и конкретным ошибочным/исправленным словам.
- Полный экзамен по-прежнему отправляет **`game_result`, `correct/total` из 5**, который учитывается в Текстории. Учебный отчёт вообще **не содержит `correct` и `total`**.
- Новый серверный обработчик записывает **только во вкладку «Тренажёры — навыки»** существующей Telegram-таблицы. Он не касается школьного журнала, вкладки «Тренажёры — результаты» и Текстории.

### Два действия в Apps Script (один раз)
1. Открой именно **действующий Google Apps Script проект Telegram-бота `@russian11_island_bot`**. Нажми слева **+ → Скрипт** и создай файл **`Ege12SkillDiagnostics.gs`**. Вставь **полностью** содержимое одноимённого готового файла. Сохрани.
2. В **этом же проекте** открой **`QuizBot.gs`**, найди **точную функцию `e4GameResult_(m)`**. В ней сразу **после** блока `try { data=JSON.parse(raw); } catch ...` и **до** строки `if (!data || data.v !== 1 || data.type !== 'game_result') return;` вставь:

```javascript
if (data && data.v === 1 && data.type === 'skill_result' &&
    data.gameId === 'ege12-celuyu-milaya')
  return e4Ege12SkillResult_(m, data);
```

Никаких других функций, в том числе `Code.gs`, **не изменять**. Существующую обработку `game_result` не удалять и не переделывать.

3. В Apps Script нажми **Развернуть → Управление развёртываниями → Изменить у существующего веб-приложения → Новая версия → Развернуть**. Адрес webhook не менять, если адрес веб-приложения прежний.

### Проверка на одном ученике
1. В личном чате бота открой **🎮 Тренажёры → Целую, милая**. Пройди **тематический подход** и нажми **📩 Передать результаты преподавателю**. Telegram может закрыть игру — это штатное поведение `sendData`.
2. Бот должен ответить «📊 Диагностика № 12 записана». Проверь вкладку **«Тренажёры — навыки»**: строки по одному ID попытки, с деталями типа `Буква в слове`, `Ошибочное слово`, `Исправленное слово`, `Шаг обучающего алгоритма` или `Запрошена подсказка`.
3. Убедись, что во вкладке **«Тренажёры — результаты»** не появилось строк с этим ID попытки и в **Текстории** нет дополнительных рейтинговых очков за учебный подход.
4. Отдельно пройди **пять полных заданий ЕГЭ**, отправь результат. Во вкладке **«Тренажёры — результаты»** должна появиться ровно одна строка с оценкой из пяти, а в Текстории — один рейтинговый подход.
5. Для проверки повторной передачи открой игру из Telegram повторно → **«Отчёты для преподавателя»** → выбери ту же попытку → «Повторить отправку». Бот должен ответить, что запись уже есть; дублей в таблице не должно появиться.

### Если не получается
- Если нет сообщения об успешной записи, открой Apps Script → **Выполнения** и найди ошибку с префиксом `EGE12_SKILLS`.
- Если отчёт остался в игре и Telegram ничего не получил, проверь, что игру запустили **через кнопку Mini App в чате бота**, а не по внешней ссылке в браузере.
- Если во вкладке «Тренажёры — навыки» данные есть, но рейтинг вырос от тематической тренировки, проверь серверный перехват `skill_result`: он должен стоять **до** блока обработки `game_result` и завершаться `return`.
