Дата: 18.11.2026. Игровая страница: https://tatibru-bot.github.io/russian11-games/games/legopunkt/

## Учёт без ошибок
- Единственная видимая кнопка каталога: `LEGOPUNKT` — `Тренажёры!A16:K16` таблицы `13kcudUD6g9zHFIigT5NllxxeUUPZuDDZwFBXfGzOLoU`.
- Служебные записи `LEGO16` — `LEGO20` в строках 17–21 имеют статус «Готов», формат Mini App, но не имеют HTTPS-ссылки: существующий бот принимает их `game_result`, не выводя отдельные пять кнопок.
- Игрок отмечается только по завершении всех семи этапов полного конструктора; режим обычной пунктуационной практики не учитывается.
- Учёт по уникальному ID предложения в локальном хранилище Telegram, повторное прохождение на этом устройстве не начисляется. Для глобального предотвращения повторов между разными устройствами нужна дополнительная проверка на сервере (пока нет).
- Сохранение кнопкой `Сохранить 1 предложение №N` передаёт ровно один завершённый разбор за одно `WebApp.sendData` (оно закрывает Mini App), другие остаются в очереди.
- Формат: `{"v":1,"type":"game_result","gameId":"LEGO17","attemptId":"LP17_<уникальный ID>","correct":1,"total":1,"errors":{}}`. Функция приёма по текущей известной версии кода — `e4GameResult_` в `QuizBot.gs`; она идентифицирует ученика по Telegram ID из message.from.id и исключает повтор attemptId.
- Старое отображение бота `/games stats` пишет `Попыток N`. Для этих служебных пяти игр **1 попытка = 1 полностью разобранное предложение**, т.к. каждый пакет передаёт ровно 1 предложение. Текст «Ошибок: 0» остаётся стандартным подтверждением бота, фактически мы не собираем ошибки и не выводим их на анализ.
- Реальная доставка сообщения Telegram в работающий webhook в текущей среде не проверена: проведена симуляция WebApp sendData и сверка структуры с сохранённым кодом приёмника. Для сквозного теста необходимо открыть игру из `/games` в **личном чате** бота, решить одно полное предложение и отправить его.

## Контроль при проверке в Telegram
1. Ученик нажимает `🎮 Тренажёры` → `ЛЕГОПУНКТ`, не просто браузерную ссылку.
2. Проходит все 7 шагов конструктора №16–20; в конце нажимает `Сохранить 1 предложение`.
3. Бот должен прислать квитанцию (в старом шаблоне «Правильно: 1 из 1, ошибок: 0»). В `Тренажёры — результаты` появляется одна строка `LEGO<N>`, в `/games stats` по номеру увеличится `Попыток` на 1.
4. В `ЛЕГОПУНКТ — сводка` для ученика увеличится соответствующий столбец на 1.
5. После разрешения импорта число появится в `Русский язык `!K:O нужной строки.

## Ограничения
- Официальный бот может иметь изменения кода после последнего доступного слепка `QuizBot.gs` от 08.11.2026. Поэтому сквозное получение через текущий Telegram webhook и реальное имя в /games stats пока требуют контрольного прохождения.
- Дедупликация между разными устройствами пока не серверная.
- Для изменения шаблона ответа «Ошибок: 0» и вывода «Разобрано N предложений» вместо «Попыток N» требуется обновить сам `QuizBot.gs` и передеплоить Apps Script; через имеющиеся инструменты Apps Script недоступен.
