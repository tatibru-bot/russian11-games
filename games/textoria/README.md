# Текстория — интеграция с ботом 11 «К»

Статус: STAGING. Ученические сообщения выключены.

## Источники

- Существующий бот: @russian11_island_bot.
- Исходные листы: «Ученики», «Тренажёры», «Тренажёры — результаты».
- Созданные листы: «Текстория — жители», «Текстория — рода», «Текстория — дуэли», «Текстория — события», «Текстория — настройки».

Начальный рейтинг рассчитан из сохранённых результатов. Пока он не пересчитывается автоматически, поэтому не публиковать его как live.

## Как запускать имеющиеся игры

Каталог вызывает глубокую ссылку Telegram с параметром start=textoria_GAMEID.
TextoriaBotLaunch.gs должен перехватить этот параметр и прислать в личный чат именно Reply Keyboard кнопку web_app, ведущую на старую игру из реестра «Тренажёры».

Только такой запуск сохраняет действующую передачу результатов через Telegram.WebApp.sendData(). Прямая ссылка на GitHub Pages из обычного браузера этот механизм не гарантирует.

## Какие модули добавить в действующий Apps Script

Код лежит в папке backend:

1. TextoriaCore.gs — подтверждённые результаты бота, рейтинг и престол.
2. TextoriaDuels.gs — Telegram HMAC, вызовы на сутки, лучший полный раунд и отдельные награды.
3. TextoriaClans.gs — создание рода, прошения, выход, гербы, эпитеты, защищённый снимок королевства.
4. TextoriaBotLaunch.gs — безопасный запуск существующих игр через бот.

В реальном QuizBot.gs:
- До обычного /start: вызвать textoriaHandleTelegramStart_(update).
- После успешной записи game_result: вызвать textoriaAfterGameResult_(result).
- По плановому таймеру: textoriaCloseExpiredDuels(), затем textoriaRebuild().

Script Properties: TEXTORIA_SPREADSHEET_ID (если необходимо), TEXTORIA_BOT_TOKEN (секрет прежнего бота), TEXTORIA_URL (ссылка после публикации). Токены не должны попадать ни в GitHub, ни в таблицу.

## Принятая формула рейтинга (20 ноября 2026)

Учебный рейтинг — максимум 100 баллов. Основан на подтверждённых играх и тестах, включая № 4 и № 7:
- 60 баллов: среднее пяти лучших рейтингов по номерам 1–15, 21–26 (при меньшем количестве недостающие места считаются нулём);
- 30 баллов: по 30/21 за каждый впервые завершённый номер из 21;
- 5 баллов: по 0,25 за уникальное полностью разобранное предложение ЛЕГОПУНКТА (№ 16–20, максимум 20);
- 3 балла: «Словарный штурм»;
- 2 балла: части речи, когда будет готов тренажёр.

Для каждого обычного номера рейтинг 0–100: 50% лучшая точность, 30% среднее последних пяти полных попыток, 20% активность (2 очка за раунд, максимум 10). Все завершённые попытки влияют на учебную статистику, включая попытки в дуэли. Дуэльная доблесть (до 12 учитываемых очков) добавляется только к игровому рейтингу.

**Рейтинг рода = среднее личных игровых рейтингов всех участников × 1,10** (если участников двое и более). Род из одного игрока имеет тот же рейтинг, что и сам игрок, без бонуса и штрафа. Одиночка участвует в борьбе за престол на равных. Коалиция не получает сумму личных баллов. Монархом победившего рода становится участник с наибольшим личным рейтингом.

Проверочный пример: Женя 50,45, Тая 49,77 → (50,45 + 49,77)/2 × 1,10 = 55,121. Илья-одиночка с 58,61 остаётся королём. Важно: добавление слабого участника может уменьшить рейтинг рода.

Настоящий клиент ещё не подключён к Apps Script; рейтинги на вкладке «Текстория — жители» являются только текущим проверочным снимком, а не live-обновлением.

## Состояние и безопасность

Выполнена только подготовка. Код в GitHub сам не устанавливается в Apps Script; запись игрового результата и уведомления пока не подключены.

- Учебная статистика остаётся единственным источником баллов, без повторного зачёта одной попытки.
- Бонус победы в дуэли хранится отдельно.
- Доступ к действиям — только ученикам 11 «К» после серверной проверки Telegram initData.
- На публичном экране показывать только имена, эпитеты, титулы и рейтинги, не фамилии и не Telegram ID.
- Параметры notify_private и notify_channel пока выключены.
- Для полной live-карты понадобится защищённое обращение к textoriaSnapshot() — прототип GitHub Pages не имеет непосредственного доступа к google.script.run.

## Проверка перед публикацией

1. Установить четыре модуля в тот же Apps Script, что QuizBot.gs, подключить маршрутизатор и результатный хук.
2. Сверить с учителем начальные данные и рейтинги 13 учеников.
3. Проверить пробный запуск игры из личного чата бота, новую строку в «Тренажёры — результаты» и её однократный учёт.
4. Подключить защищённый клиентский шлюз, затем проверить дуэли и вступление в род.
5. Только после успешной проверки включить Telegram-оповещения и объединить staging с основной веткой.
