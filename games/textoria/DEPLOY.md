# Запуск Текстории в главном меню бота

СТАТУС: подготовлено в ветке feat/textoria-integration, но НЕ установлено в действующий QuizBot.gs. Ученические сообщения и канал «Будни» не затронуты.

## Принцип

Кнопка «👑 Текстория» — на главном экране бота. Она располагается рядом с «Моя статистика», а не внутри списка «Тренажёры».

Сама Текстория запускается как HTMLService Mini App. Она проверяет Telegram initData на сервере, загружает актуальные результаты из листов «Тренажёры — результаты» и «Результаты» и показывает только авторизованный кабинет. Никаких оценок школьников в публичном коде GitHub нет.

Код страницы: games/textoria/backend/TextoriaWeb.html.
Серверные файлы:
- TextoriaCore.gs
- TextoriaDuels.gs
- TextoriaClans.gs
- TextoriaBotLaunch.gs
- TextoriaWebGateway.gs

Все шесть файлов должны находиться внутри того же Apps Script проекта, что QuizBot.gs; изменения в GitHub сами не разворачивают Apps Script.

## Подключение к текущему боту

1. Открыть существующую таблицу бота в Google Sheets → Расширения → Apps Script.
2. Добавить файлы из папки backend без изменения старого обработчика записей.
3. В существующей функции doGet(e) первым условием добавить:

    if (e && e.parameter && e.parameter.page === 'textoria')
      return textoriaWebPage(e);

   Не создавать вторую функцию doGet: это сломает старые маршруты.
4. В том месте, где формируется массив кнопок *главного меню* (не каталога игр), вызвать:

    inlineKeyboard = textoriaAddToMainMenu_(inlineKeyboard);

   Получившаяся клавиатура сохраняет старые кнопки и добавляет ровно один ряд с кнопкой Текстории.
5. В общем обработчике сообщений перед обработкой обычного /start:

    if (textoriaHandleTelegramStart_(update)) return;

   Это нужно для запуска старых тренажёров по безопасной Reply Keyboard Web App кнопке.
6. После подтверждённой записи game_result в существующую вкладку результатов:

    textoriaAfterGameResult_(result);

   Передавать уже разобранную и проверенную структуру game_result, не клиентские произвольные проценты.
7. В Script Properties указать:
   - TEXTORIA_SPREADSHEET_ID — ID существующей таблицы бота.
   - TEXTORIA_BOT_TOKEN — тот же секретный токен, что у работающего бота (только Script Properties).
   - TEXTORIA_WEBAPP_URL — URL /exec опубликованного Apps Script.
8. Развернуть Apps Script Web App (Execute as Me; Who has access Anyone). Доступ к содержимому приложения, действиям и личным оценкам определяется серверной проверкой Telegram initData.
9. Прежде чем показывать кнопку всему классу, выполнить в личном чате Telegram тест с одним зарегистрированным учеником. Сверить профиль с Google Sheet, выполнить 1 тренировку, проверить запись ровно 1 попытки, отправить предложение союза и принять его со второго аккаунта.
10. Создать плановый запуск textoriaCloseExpiredDuels и затем textoriaRebuild каждые 5–15 минут; не объединять их под одним удерживаемым LockService.

## Текущие ограничения

Основное приложение и серверные функции готовы к установке, но реальный бот сейчас их НЕ исполняет: проект QuizBot.gs нельзя изменить через предоставленный GitHub/Google Drive коннектор. Не объявлять релиз до живой Telegram-проверки.

Дворцовые указы, тренажёр дня и публикация в канал — пока закрытые будущие механики.
Уведомления личными сообщениями выключены в настройках до проверки безопасной отправки.
Чужие Telegram ID и фамилии не отправляются в клиентское приложение.
